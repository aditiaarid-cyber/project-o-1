# PROJECT O

## Tentang Project O

**Project O** adalah sebuah project pengembangan platform permainan berbasis website yang menyediakan berbagai macam **board game yang dapat dimainkan secara digital**. Project ini dibuat untuk menjadi sebuah wadah yang memungkinkan pengguna mengakses dan memainkan berbagai permainan dalam satu platform.

Project O dikembangkan secara bertahap. Setiap permainan yang dibuat akan menjadi bagian dari platform dan dapat ditambahkan ke dalam website tanpa harus mengubah keseluruhan sistem yang sudah ada.

Pada tahap awal pengembangan, **Werewolf** dipilih sebagai game pertama yang akan dikembangkan dan diintegrasikan ke dalam Project O.

## Tujuan Project

Project O dibuat dengan beberapa tujuan utama, yaitu:

1. Membuat sebuah website yang dapat menjadi wadah berbagai board game.
2. Mengembangkan permainan board game yang dapat dimainkan secara digital.
3. Membuat struktur project yang memungkinkan game baru ditambahkan di kemudian hari.
4. Menerapkan penggunaan **GitHub** sebagai tempat penyimpanan dan pengelolaan source code.
5. Menerapkan sistem kerja sama dalam pengembangan software menggunakan **Visual Studio Code** dan Git.
6. Membagi tanggung jawab pengembangan berdasarkan bagian masing-masing agar proses pengerjaan lebih terorganisir.

## Pengembangan Awal

Pada tahap pertama, Project O terdiri dari dua bagian utama:

### 1. Website / Platform

Website berfungsi sebagai wadah utama Project O. Bagian ini bertanggung jawab terhadap tampilan, navigasi, halaman daftar game, serta akses pengguna menuju game yang tersedia.

**Penanggung jawab: Adit**

### 2. Game Werewolf

Werewolf merupakan game pertama yang dikembangkan untuk Project O. Game ini akan memiliki sistem permainan seperti pembagian role, fase malam, fase siang, diskusi, voting, serta kondisi kemenangan dan kekalahan.

**Penanggung jawab: Aji**

## Sistem Kerja Tim

Project O dikembangkan oleh dua orang dengan pembagian tanggung jawab yang jelas.

| Anggota  | Tanggung Jawab                 |
| -------- | ------------------------------ |
| **Adit** | Website dan platform Project O |
| **Aji**  | Pengembangan game Werewolf     |

Setiap anggota bertanggung jawab terhadap bagian yang telah ditentukan dan tidak mengambil alih pekerjaan utama anggota lainnya.

Meskipun memiliki tanggung jawab masing-masing, kedua anggota tetap melakukan **review dan pengecekan** terhadap hasil pekerjaan satu sama lain. Tujuannya adalah menemukan bug, kesalahan, atau masalah integrasi sebelum suatu bagian digabungkan ke project utama.

## Teknologi dan Tools

Project O menggunakan beberapa tools utama dalam proses pengembangan:

* **Visual Studio Code** — digunakan sebagai code editor.
* **Git** — digunakan untuk mengelola perubahan source code.
* **GitHub** — digunakan sebagai repository dan tempat kolaborasi project.
* **Web Technologies** — digunakan untuk membangun platform website dan game berbasis web.

## Pengembangan Berkelanjutan

Project O dirancang agar tidak hanya memiliki satu game. Setelah Werewolf selesai dikembangkan, platform dapat dikembangkan lebih lanjut dengan menambahkan board game lainnya.

Dengan demikian, Project O diharapkan dapat berkembang menjadi sebuah platform yang memiliki berbagai pilihan permainan dalam satu website.
